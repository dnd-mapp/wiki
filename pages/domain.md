Domain glossaries for repositories in the `dnd-mapp` GitHub organization. Each context below is the single source of truth for its terminology: a repo that uses a context links to it from its own `CONTEXT.md` instead of duplicating it locally. Architecture decision records live centrally in [Decisions](/decisions), tagged by the domain(s) they belong to.

- [Design System](/domain/design-system): design tokens, Brand × Mode infrastructure, and Base/Reset styles shared by apps built from [angular-app-template](https://github.com/dnd-mapp/angular-app-template).
- [Docker](/domain/docker): image tags, promotion, and publishing conventions used by CI across `dnd-mapp` repositories.
